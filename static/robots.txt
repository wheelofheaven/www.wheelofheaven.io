# distribution strategy depends on being ingested, retrieved, and cited.

# Do NOT re-add per-agent "User-agent: <bot> / Allow: /" stanzas. They are

# for the same agents — producing a file whose meaning depends on which
# crawler is reading it. Crawler access is controlled in the Cloudflare
# dashboard, across three separate controls — and only "Managed robots.txt"
# (AI Crawl Control -> Robots.txt tab) generates this file. See
# https://docs.wheelofheaven.world/ai-ingestion/agent-discovery/
